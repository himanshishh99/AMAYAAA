# AMAYA

AI-powered healthcare infrastructure platform for elderly and chronic care.

## Monorepo Structure

frontend/  -> React dashboard + caregiver UI  
backend/   -> Express REST API + MQTT bridge  
iot-simulator/ -> Smart pillbox event simulator  
docs/      -> architecture & deployment notes  

## Features
- AI-assisted triage
- medication adherence monitoring
- caregiver alerts
- vitals tracking
- queue intelligence
- secure healthcare APIs

## Stack
React • Express • MQTT • JWT • Node-Cron • PostgreSQL
